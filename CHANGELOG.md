# Changelog

## 2.1.1

- Explicitly added the Aurora hover commands to the VS Code Command Palette menu so they are always discoverable after installation.
- No icon design changes; this patch improves command visibility and installation verification.

## 2.1.0

- Added the **Aurora hover feature directly to Masum Galaxy // Product Icons**.
- Added `ui/product-icon-hover.css` for Product Icon hover styling.
- Added commands to enable, disable and reload Aurora hover.
- Added optional integration with **Custom CSS and JS Loader**.
- Hovering Product Icons now adds a cyan → blue → violet glow, subtle lift/scale and an Activity Bar halo.
- Added migration logic so an enabled hover import can follow newer installed extension versions.
- Product Icon glyphs remain official VS Code Product Icon Theme contributions; only the optional hover animation uses custom CSS.

## 2.0.0

- Rebuilt the product icon font to match the approved **Premium Galaxy / Before vs After** design direction.
- Added **41 distinct custom glyphs** covering the main VS Code UI and important secondary actions.
- Main Activity Bar redesign: orbital Explorer folder, spark Search, constellation Source Control, rocket Run, cube Extensions, flask Testing, orbital Account and reactor-style Settings.
- Added dedicated Premium Galaxy icons for Terminal, New File, New Folder, Refresh, Sync, Close, Split, Git Branch, Pull, Push, Warning, Info, Error, Notifications and Layout.
- Added dedicated Back, Forward, Up, Down, Trash, Preview, Edit, Check, Pin, Cloud, Download, Upload, Database and Bug glyphs.
- Expanded mappings to more than **200 high-value VS Code product icon IDs**.

## 1.3.0

- Redesigned the custom WOFF icon font for a more polished, futuristic look.

## 1.2.1

- Fixed square / missing glyph rendering.

## 1.0.0

- Initial **Masum Galaxy // Product Icons** release.
